# Флаги языков

SVG-флаги взяты из проекта [flag-icons](https://github.com/lipis/flag-icons)
версии 7.2.3 (лицензия MIT, см. `LICENSE`).

Файлы называются по коду страны, а не по коду языка: например,
английский использует `gb.svg`, белорусский — `by.svg`, грузинский —
`ge.svg`. Соответствие задано в `shared/locales/*.js` в поле `flag`.
