# Store descriptions

44 текста для поля `Description` в Chrome Web Store — по одному файлу на язык.

Как использовать:

1. Открой CWS → Store listing → `Current editing language`.
2. Выбери язык.
3. Открой соответствующий `.txt` и скопируй всё содержимое в поле `Description`.
4. Сохрани черновик и проверь следующий язык.

`pt.txt` используется для двух локалей CWS: `pt_BR` и `pt_PT`.

Файлы сгенерированы из `source/*.js` командой:

```bash
node store-descriptions/generate.js
```
