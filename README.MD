# erst_dev_adblocker

Блокировщик рекламы для Chrome на Manifest V3.

## Что это

Расширение блокирует рекламные запросы на уровне сети (DNR), скрывает баннеры через CSS, пропускает рекламу в видео. Работает на всех сайтах, с возможностью отключения на отдельных сайтах через белый список.

## Требования

- Node.js 18+ (для сборки и конвертера).
- Chrome 105+ (для работы).

## Быстрый старт

```bash
# Установить зависимости
npm install

# Сконвертировать списки правил (первый раз или после обновления EasyList)
npm run convert

# Сгенерировать иконки (один раз, из исходников в корне)
npm run icons

# Собрать ZIP для публикации
npm run build
