# Глава 3. Manifest.json — паспорт расширения

## Зачем эта глава

`manifest.json` — самый важный файл в расширении. Без него Chrome **вообще не поймёт**, что ты загрузил. Это *
*единственный** файл, который Chrome читает **до того**, как запустит хоть одну строчку твоего кода.

Он отвечает на вопросы:

- Как называется расширение?
- Какие права ему нужны?
- Какие скрипты запускать и где?
- Какой файл показывает popup?
- Где лежат DNR-правила?

**Глава даёт обзор каждого поля.** Детали — в главах 4, 5, 6, 8.

## Полный manifest.json нашего проекта

```json
{
  "manifest_version": 3,
  "name": "erst_dev_adblocker",
  "version": "0.7",
  "description": "Блокировщик рекламы",
  "permissions": [
    "declarativeNetRequest",
    "scripting",
    "storage",
    "webNavigation",
    "tabs"
  ],
  "host_permissions": [
    "<all_urls>"
  ],
  "background": {
    "service_worker": "background/service_worker.js",
    "type": "module"
  },
  "content_scripts": [
    {
      "matches": [
        "*://*/*"
      ],
      "js": [
        "content/lib/state.js",
        "content/lib/inject-css.js",
        "content/lib/spa.js",
        "content/lib/observer.js",
        "content/lib/auto-skip.js",
        "content/lib/ad-markers.js",
        "content/domain-cosmetic.js"
      ],
      "run_at": "document_start"
    }
  ],
  "action": {
    "default_title": "erst_dev_adblocker",
    "default_popup": "popup/popup.html"
  },
  "declarative_net_request": {
    "rule_resources": [
      {
        "id": "ads_ruleset",
        "enabled": false,
        "path": "rules/ads.json"
      },
      {
        "id": "exceptions_ruleset",
        "enabled": false,
        "path": "rules/exceptions.json"
      },
      {
        "id": "manual_ruleset",
        "enabled": false,
        "path": "rules/manual.json"
      }
    ]
  },
  "web_accessible_resources": [
    {
      "resources": [
        "rules/cosmetic-map.json"
      ],
      "matches": [
        "<all_urls>"
      ]
    }
  ]
}
```

## Разбор по полям

### `manifest_version`

```json
"manifest_version": 3
```

**Что это:** версия **правил**, по которым Chrome работает с расширением.

**Почему** `3`: Chrome поддерживает только MV3 для новых расширений. MV2 устарел — с 2023 года постепенно отключается.
Если поставить `2`, Chrome откажется загружать или загрузит с предупреждением о скором отключении.

**Про** **MV2** **vs** **MV3** — **в** **главе** **1**.

### `name`, `version`, `description`

```json
"name": "erst_dev_adblocker",
"version": "0.7",
"description": "Блокировщик рекламы"
```

**Что это:** метаданные для Chrome Web Store и страницы `chrome://extensions`.

- **`name`** — имя расширения. Показывается в магазине, в списке расширений, в тултипе иконки.
- **`version`** — число вида `major.minor.patch`. Chrome использует его, чтобы понять, что расширение обновилось. Мы
  инкрементим при каждом значимом изменении.
- **`description`** — короткое описание. В магазине — до 132 символов.

⚠️ **При** **публикации** **в** **Chrome** **Web** **Store** **версию** **нельзя** **понизить**.** **Каждое** *
*обновление** — **новая** **версия** **больше** **предыдущей**.

### `permissions`

```json
"permissions": [
  "declarativeNetRequest",
  "scripting",
  "storage",
  "webNavigation",
  "tabs"
]
```

**Что это:** список **прав**, **которые** **нужны** **расширению**.** **Chrome** **показывает** **пользователю** *
*список** **прав** **при** **установке**.** **Без** **права** — **соответствующий** **API** **недоступен**.

**Разбор** **каждого** **права:**

#### `declarativeNetRequest`

**Что даёт:** право **блокировать**, **перенаправлять** **или** **изменять** **сетевые** **запросы** **через** *
*декларативные** **правила** (**DNR**).

**Зачем** **нам:** **основная** **функция** **блокировщика** — **резать** **запросы** **к** **рекламным** **доменам**.

**Как** **работает:** **мы** **описываем** **правила** **в** **JSON-файлах** (`rules/ads.json`), **Chrome** **сам** *
*применяет** **их** **до** **того**, **как** **запрос** **уйдёт** **в** **сеть**.** **Наш** **код** **в** **этом** **не
** **участвует** — **только** **декларация**.

**Если** **убрать:** **блокировка** **сети** **перестанет** **работать**.** **Останется** **только** **косметика** (*
*скрытие** **CSS**).

**Подробно:** **глава** **8**.

#### `scripting`

**Что даёт:** право **вставлять** **CSS** **и** **JS** **в** **страницы** **через** `chrome.scripting`.

**Зачем** **нам:** **service** **worker** **вставляет** **общий** **CSS** (`cosmetic.css` + `cosmetic-manual.css`) **на
** **каждую** **страницу** **через** `chrome.scripting.insertCSS`.

**Почему** **не** **обойтись** **без** **него:** **content** **script** **не** **имеет** **доступа** **к**
`chrome.scripting`.** **Вставить** **CSS** **в** **чужую** **вкладку** **может** **только** **service** **worker** — *
*через** **это** **право**.

**Если** **убрать:** **общий** **CSS** **не** **будет** **вставляться**.** **Косметика** **на** **любом** **сайте** *
*сломается**.

**Подробно:** **глава** **4**.

#### `storage`

**Что даёт:** право **читать** **и** **писать** **в** `chrome.storage` — **общее** **хранилище** **расширения**.

**Зачем** **нам:** **хранить** **настройки** — **включено**/**выключено** **расширение**, **список** **исключений** *
*сайтов**.

**Особенность:** **в** **MV3** **service** **worker** **засыпает**, **все** **переменные** **в** **нём** **обнуляются
**.** **Единственный** **надёжный** **способ** **хранить** **настройки** **между** **пробуждениями** — `chrome.storage`.

**Если** **убрать:** **не** **получится** **сохранить** **выбранные** **настройки**.** **Расширение** **всегда** **будет
** **в** **одном** **состоянии** **(по** **умолчанию** **включено**, **список** **пуст**).

**Подробно:** **глава** **7**.

#### `webNavigation`

**Что даёт:** право **слушать** **события** **навигации** — **открытие** **новой** **страницы**, **переходы** **внутри**
**сайта**, **смена** **URL**.

**Зачем** **нам:** **service** **worker** **подписывается** **на** `chrome.webNavigation.onCommitted`.** **Когда** *
*открывается** **новая** **страница** — **мы** **вставляем** **в** **неё** **общий** **CSS**.

**Почему** **не** **через** **content_scripts**:** **content** **scripts** **запускаются** **на** **каждой** **странице
** **сами**, **но** **у** **них** **нет** **доступа** **к** `chrome.scripting`.** **Вставить** **CSS** **может** *
*только** **service** **worker**, **а** **чтобы** **он** **знал**, **когда** **вставлять** — **нужно** **слушать** *
*навигацию**.

**Если** **убрать:** **service** **worker** **не** **узнает** **о** **новых** **страницах**.** **Общий** **CSS** **не***
*будет** **вставляться**.

**Подробно:** **глава** **4**.

#### `tabs`

**Что даёт:** право **читать** **информацию** **о** **вкладках** — **URL**, **заголовок**, **какая** **активна**.

**Зачем** **нам:**
- Popup просит у `chrome.tabs.query` активную вкладку, чтобы показать состояние именно для неё.

**Если** **убрать:** popup не сможет понять, на каком сайте он открыт — не будет знать, какой домен добавлять в белый список и показывать как текущий.

**Подробно:** **глава** **6**.

### `host_permissions`

```json
"host_permissions": ["<all_urls>"]
```

**Что это:** **отдельный** **список** **прав** **в** **MV3** — **«разрешение** **работать** **на** **этих** **сайтах»
**.** **`<all_urls>`** — **на** **всех** **сайтах** **вообще**.

**Зачем** **нам:** **блокировщик** **должен** **работать** **везде**.** **Если** **ограничить** **список** — **реклама**
**останется** **на** **всех** **остальных** **сайтах**, **что** **бессмысленно**.

**Почему** **отдельно** **от** **`permissions`:** **в** **MV3** **Google** **вынес** **доступ** **к** **сайтам** **в** *
*отдельный** **блок** — **чтобы** **пользователь** **видел** **явно**:** **«Это** **расширение** **хочет** **читать** *
*и** **менять** **все** **ваши** **данные** **на** **всех** **сайтах»**.** **Это** **самое** **«страшное»** *
*предупреждение** **Chrome** — **и** **блокировщики** **без** **него** **не** **работают**.

**Если** **убрать:** **расширение** **не** **сможет** **вставлять** **CSS**, **резать** **запросы**, **видеть** *
*вкладки** **—** **ничего**.

**Подробно:** **глава** **1** **и** **глава** **8**.

### `background`

```json
"background": {
  "service_worker": "background/service_worker.js",
  "type": "module"
}
```

**Что это:** указание, **какой** **файл** **запускать** **в** **фоне**.

**Разбор:**

- **`service_worker`** — **путь** **к** **файлу**.** **В** **MV3** **фон** — **это** **service** **worker**, **не** *
  *HTML-страница** (**как** **в** **MV2**).
- **`type: "module"`** — **говорит** **Chrome**, **что** **этот** **файл** **—** **ES-модуль**.** **Это** **значит**: *
  *внутри** **можно** **использовать** `import`/**`export`**.** **У** **нас** **service** **worker** **импортирует** *
  *модули** **из** `background/lib/` **и** `shared/` — **поэтому** **нужен** `type: "module"`.

⚠️ **Почему** **`type: "module"`** **только** **здесь**, **а** **не** **у** **content** **scripts**:** **content** *
*scripts** **не** **поддерживают** **ES-модули**.** **Об** **этом** — **в** **разделе** **про** **content_scripts** *
*ниже** **и** **в** **главе** **5**.

**Подробно:** **глава** **4**.

### `content_scripts`

```json
"content_scripts": [
  {
    "matches": ["*://*/*"],
    "js": [
      "content/lib/state.js",
      "content/lib/inject-css.js",
      "content/lib/spa.js",
      "content/lib/observer.js",
      "content/lib/auto-skip.js",
      "content/lib/ad-markers.js",
      "content/domain-cosmetic.js"
    ],
    "run_at": "document_start"
  }
]
```

**Что это:** указание, **какие** **скрипты** **запускать** **в** **каждой** **вкладке**.

**Разбор:**

- **`matches`** — **на** **каких** **URL** **запускать**.** `*://*/*`** — **на** **любых** **сайтах** **по** **любому***
  *протоколу** (**http**, **https**).
- **`js`** — **массив** **файлов**.** **Chrome** **выполняет** **их** **ПОСЛЕДОВАТЕЛЬНО** **в** **общем** **контексте
  **.** **Функции** **из** **первого** **файла** **доступны** **второму**, **и** **так** **далее**.** **Порядок** *
  *КРИТИЧЕН**.
- **`run_at`** — **когда** **запускать**.** `document_start`** — **до** **того**, **как** **страница** **начнёт** *
  *отрисовываться**.** **Это** **нужно**, **чтобы** **реклама** **не** **успела** **мигнуть** **до** **нашего** **CSS**.

⚠️ **Почему** **массив** **из** **семи** **файлов**, **а** **не** **один**:** **content** **scripts** **не** *
*поддерживают** **ES-модули**.** **Мы** **не** **можем** **написать** `import` **внутри** **content** **script**.** *
*Решение** — **разбить** **на** **файлы** **и** **подключить** **их** **массивом**.** **Chrome** **выполнит** **их** **в
** **одном** **общем** **контексте**, **как** **если** **бы** **они** **были** **одним** **файлом**.

**Порядок** **важен:**

1. **`state.js`** — **определяет** **глобальный** **объект** `state`.** **Все** **остальные** **его** **используют**.
2. **`inject-css.js`** — **определяет** `fetchSelectors`, `applySelectors`, `refreshSelectors`.
3. **`spa.js`** — **использует** `refreshSelectors`.
4. **`observer.js`** — **использует** `state`.
5. **`auto-skip.js`** — **самодостаточен**.
6. **`ad-markers.js`** — **самодостаточен**.
7. **`domain-cosmetic.js`** — **точка** **входа**, **вызывает** **функции** **из** **всех** **предыдущих**.** **Идёт** *
   *ПОСЛЕДНИМ**.

⚠️ **Если** **поменять** **порядок** **или** **забыть** **файл** — **сломается**.** **Chrome** **не** **проверит** **за
** **тебя** **правильность** **порядка**.

**Подробно:** **глава** **5**.

### `action`

```json
"action": {
  "default_title": "erst_dev_adblocker",
  "default_popup": "popup/popup.html"
}
```

**Что это:** настройка **кнопки** **расширения** **в** **тулбаре** **Chrome** (**справа** **от** **адресной** **строки
**).

**Разбор:**

- **`default_title`** — **текст** **тултипа** **при** **наведении** **на** **иконку**.
- **`default_popup`** — **путь** **к** **HTML-файлу** **попапа**.** **Откроется** **при** **клике** **на** **иконку**.

⚠️ **Про** **иконку**:** **в** **манифесте** **нет** `default_icon` — **Chrome** **покажет** **стандартную** **иконку***
*расширения**.** **Свою** **иконку** **добавляют** **через** **это** **поле**.

**Подробно:** **глава** **6**.

### `declarative_net_request`

```json
"declarative_net_request": {
  "rule_resources": [
    {
      "id": "ads_ruleset",
      "enabled": false,
      "path": "rules/ads.json"
    },
    {
      "id": "exceptions_ruleset",
      "enabled": false,
      "path": "rules/exceptions.json"
    },
    {
      "id": "manual_ruleset",
      "enabled": false,
      "path": "rules/manual.json"
    }
  ]
}
```

**Что это:** указание **Chrome**, **где** **лежат** **наши** **DNR-правила** **блокировки**.** **Chrome** **читает** *
*эти** **файлы** **при** **загрузке** **расширения** **и** **применяет** **их** **автоматически** **ко** **всем** *
*сетевым** **запросам**.

**Разбор:**

- **`id`** — **имя** **ruleset'а**.** **Используется** **в** **коде** (
  `chrome.declarativeNetRequest.updateEnabledRulesets`) — **чтобы** **включать**/**выключать** **ruleset** **целиком**.
- **`enabled`** — **включён** **ли** **ruleset** **при** **старте**.** **У** **нас** `false` **у** **всех** **трёх** — *
  *потому** **что** **мы** **управляем** **ими** **программно**.** **При** **запуске** **service** **worker** **читает**
  **настройки** **пользователя** **и** **включает** **ruleset'ы**, **если** **расширение** **включено**.
- **`path`** — **путь** **к** **файлу** **с** **правилами**.

⚠️ **Почему** **`enabled: false`**, **а** **не** `true`:** **Если** **поставить** `true`, **Chrome** **включит** *
*правила** **при** **старте**, **и** **наш** **код** **не** **сможет** **их** **выключить** **до** **первой** *
*синхронизации**.** **Плюс** — **при** **выключенном** **расширении** **правила** **всё** **равно** **работали** **бы
**.** **Через** **`false`** **мы** **полный** **контроль** **над** **состоянием** **берём** **на** **себя**.

**Три** **ruleset'а:**

- **`ads_ruleset`** — **блокирующие** **правила** **из** `rules/ads.json`.** **~28 000** **правил**.
- **`exceptions_ruleset`** — **разрешающие** **правила** **из** `rules/exceptions.json`.** **~500** **правил**.** *
  *Приоритет** **выше**, **чем** **у** **блокирующих** — **позволяет** **не** **резать** **то**, **что** **нельзя** *
  *резать**.
- **`manual_ruleset`** — **ручные** **правила** **из** `rules/manual.json`.** **Домен** **в** **ручную** **добавленные**
  **блокировки** (`mradx.net`, **реклама** **ВК**, **и** **т.д.).

**Подробно:** **глава** **8** **и** **глава** **9**.

### `web_accessible_resources`

```json
"web_accessible_resources": [
  {
    "resources": ["rules/cosmetic-map.json"],
    "matches": ["<all_urls>"]
  }
]
```

**Что это:** указание, **какие** **внутренние** **файлы** **расширения** **можно** **запросить** **из** **кода** *
*расширения** **и** **со** **стороны** **страниц**.

**Зачем** **нам:** **service** **worker** **делает** `fetch` **к** **файлу** `rules/cosmetic-map.json`, **чтобы** *
*прочитать** **карту** **селекторов**.** **По** **умолчанию** **Chrome** **запрещает** **расширению** **читать** **свои
** **файлы** **через** `fetch` — **нужно** **явно** **разрешить**.

**Разбор:**

- **`resources`** — **список** **файлов**, **которые** **разрешаем** **запрашивать**.** **У** **нас** — **только**
  `cosmetic-map.json` (**единственный** **файл**, **который** **мы** **читаем** **в** **рантайме**).** **Остальные** *
  *DNR-файлы** **Chrome** **читает** **сам**, **им** **этот** **раздел** **не** **нужен**.
- **`matches`** — **с** **каких** **страниц** **можно** **запросить**.** `<all_urls>` — **отовсюду**.** **Для** **нашего
  ** **случая** — **без** **разницы**, **запрос** **идёт** **из** **самого** **расширения**, **а** **не** **со** *
  *страницы**.** **Но** **оставляем** **как** **есть** — **работает**.

**Подробно:** **глава** **4**.
